# 🌍 WanderNest – Explore Hidden India

> A modern, responsive travel website designed to showcase beautiful and lesser-known destinations across India.

🔗 **Live Website:** https://jashan-0001.github.io/WanderNest/

🔗 **GitHub Repository:** https://github.com/jashan-0001/WanderNest

---

## 📌 Project Overview

**WanderNest – Explore Hidden India** is a modern three-page travel website created using **HTML5 and CSS3**.

The website is designed to provide users with an attractive and simple way to discover hidden and beautiful destinations across India.

The project focuses on:

- Clean and modern UI design
- Responsive layouts
- Smooth CSS animations
- Destination cards
- Travel planning information
- Navigation between multiple pages
- Mobile-friendly design
- Professional visual presentation

This project was developed as a **college front-end web development project** and is hosted publicly using **GitHub Pages**.

---

## ✨ Features

### 🏠 Home Page

The home page provides an attractive introduction to WanderNest.

Features include:

- Cinematic hero section
- Travel-focused heading and introduction
- Call-to-action button
- Premium navigation bar
- Smooth hover animations
- Responsive design
- Modern typography and spacing

---

### 🏔️ Destinations Page

The destinations page showcases selected travel destinations across India.

Featured destinations include:

- 🏔️ Spiti Valley
- 🌿 Meghalaya
- 🏞️ Sikkim
- 🕌 Rajasthan
- 🌄 Kasol
- 🌳 Ziro Valley

Each destination is presented using a visually attractive destination card containing:

- Destination image
- Location information
- Destination title
- Short description
- Call-to-action elements
- Hover effects

- Travel tips
- Responsive sections
